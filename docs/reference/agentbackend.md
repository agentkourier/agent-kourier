## Header

Header is a static HTTP header. Set exactly one of value and valueSecretRef; valueSecretRef's key defaults to "token", as for the other single-value Secret references. A header that carries or selects identity is refused, because the Binding identity owns it: Authorization, Proxy-Authorization, Cookie, X-User-Id, X-Agent-Name, X-Share-Token and X-Kagent-Insecure-Runtime-Identity.

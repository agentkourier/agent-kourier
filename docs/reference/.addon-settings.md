<!-- --8<-- [start:settings] -->
| Variable | Default | What it does | Chart value |
|---|---|---|---|
| `LISTEN_ADDR` | `127.0.0.1:8090` | Where the add-on listens, as `host:port`. | Always `:8090` |
| `PUBLIC_URL` | `http://` + `LISTEN_ADDR` + `/a2a` | The endpoint the agent card names: the URL Agent Kourier reaches. An `http` or `https` URL with a host. | Always `http://<fullname>-<name>.<namespace>.svc:8090/a2a` |
| `AUTH_TOKEN_FILE` | None | The file of accepted tokens. The add-on does not start unless exactly one caller check is set: this file, `AUTH_DISABLED`, or a check of the add-on's own that its [Caller check](#caller-check) names. | Always `/etc/agent-kourier-<name>/auth/tokens`, the key of `addons.<name>.auth.tokenSecret` |
| `AUTH_HEADER` | `Authorization` | The header that carries the token. Must be a header name, and not one of the reserved names in [Caller check](#caller-check). | `addons.<name>.auth.header` |
| `AUTH_DISABLED` | `false` | `true` turns the caller check off, on a loopback `LISTEN_ADDR` only. | Never set |
| `STORE` | `sqlite` | `sqlite` or `postgres`. | `addons.<name>.store.type` |
| `SQLITE_PATH` | `<name>-addon.db` | The SQLite file, with `STORE=sqlite`. | Always `/data/<name>.db`, on the claim `<fullname>-<name>-data` or `addons.<name>.persistence.existingClaim` |
| `POSTGRES_DSN` | Required with `postgres` | The connection string, as pgx reads it. Refused with `STORE=sqlite`. | `addons.<name>.store.postgres.dsnSecret` |
| `TASK_RETENTION` | `720h`<!--addon-limit:kit.task-retention--> | How long a settled task and its message IDs are kept after its last update. `0` keeps them. | `addons.<name>.taskRetention` |
| `SESSION_IDLE_TTL` | `2160h`<!--addon-limit:kit.session-idle-ttl--> | How long a context may go without activity, with no turn running, before the add-on releases it ([Sessions and their lifetime](#sessions-and-their-lifetime) says what that deletes). `0` never releases one. | `addons.<name>.sessionIdleTTL` |
| `LEASE_DURATION` | `15s`<!--addon-limit:kit.lease-duration--> | Refused with `STORE=sqlite`. More than zero, and longer than the renew deadline. How long a lease lasts without renewal. | `addons.<name>.leaderElection.leaseDuration` |
| `LEASE_RENEW_DEADLINE` | `10s`<!--addon-limit:kit.lease-renew-deadline--> | Refused with `STORE=sqlite`. More than zero, and longer than `1.2`<!--addon-limit:kit.lease-jitter--> times the retry period. How long the leader keeps trying to renew. | `addons.<name>.leaderElection.renewDeadline` |
| `LEASE_RETRY_PERIOD` | `2s`<!--addon-limit:kit.lease-retry-period--> | Refused with `STORE=sqlite`. More than zero. How often a replica tries to take or renew the lease. | `addons.<name>.leaderElection.retryPeriod` |
| `ADVERTISE_URL` | Required with `postgres` | An `http` or `https` URL with a host, where the other replicas reach this one. An IPv6 address without brackets is bracketed. | Always `http://$(POD_IP):8090`, from the downward API |
| `POD_NAME` | The hostname | This replica's name as a lease holder. | The pod's name, with Postgres |
| `LOG_LEVEL` | `info` | `debug`, `info`, `warn` or `error`. Logs are JSON on standard error. | `addons.<name>.logLevel` |

# Code of Conduct

Agent Kourier follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository's issues, pull requests and discussions, and anywhere you represent
the project.

## Reporting

Report unacceptable behaviour privately to the maintainer at
[security@agentkourier.dev](mailto:security@agentkourier.dev), with "Code of Conduct" in the
subject. Reports are handled in confidence. The maintainer reviews every report and decides on a
response using the Contributor Covenant's enforcement guidelines: correction, warning, temporary
ban or permanent ban.
